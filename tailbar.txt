FlashcardApplication.java — Програмын эхлэл (main)
----------------------------------------------------
Програм эхлэхэд энд орж ирнэ.
CLI аргументуудыг задлах → картуудыг файлаас уншах → StudySession ажиллуулах
гэсэн 3 алхмыг дараалан гүйцэтгэнэ.
Алдаа гарвал хэрэглэгчид монгол мессеж гаргаж, програмыг зогсооно.


model/Card.java — Нэг карт
---------------------------
Асуулт (question) ба хариу (answer) хадгалдаг энгийн өгөгдлийн бүтэц.
id нь картыг таних дугаар.
inverted() метод нь --invertCards сонголт ашиглагдах үед
асуулт-хариуг урвуулж өгдөг.


io/CardDeckLoader.java — Файл уншигч
--------------------------------------
my-cards.txt файлыг мөр мөрөөр уншиж карт болгодог.
Форматыг "асуулт|хариу" гэж хүлээнэ.
# тэмдгээр эхэлсэн мөр бол тайлбар (алгасна).
\| бичвэл | тэмдгийг утга болгож ойлгодог (escape).


cli/FlashcardCliParser.java — Командын мөрийн аргументуудыг задлагч
---------------------------------------------------------------------
"flashcard my-cards.txt --order worst-first --repetitions 2" гэх мэт
командыг задлаж FlashcardConfiguration объект болгодог.
Буруу аргумент бол CliParsingException буцаана.


cli/FlashcardConfiguration.java — Тохиргоо
--------------------------------------------
Задласан аргументуудыг хадгалах энгийн record:
файлын нэр, дараалал, давталтын тоо, урвуулах эсэх.


organizer/ — Картын дараалал тодорхойлогч
------------------------------------------
RandomCardOrganizer      : Картуудыг санамсаргүй холино
WorstFirstSorter         : Хамгийн олон алдаатай картаас эхэлнэ
RecentMistakesFirstSorter: Өмнөх тойрогт буруу хариулсан картаас эхэлнэ
CardOrganizerFactory     : --order утгаас харгалзах класс үүсгэнэ

CardOrganizer бол interface — дээрх 3 класс үүнийг хэрэгжүүлдэг.


session/StudySession.java — Сессийн гол логик
----------------------------------------------
Хамгийн чухал файл. Дараах урсгалаар ажиллана:
1. Бүх картаа "давсан" болох хүртэл тойрог давтана
2. Тойрог бүрт карт бүрийн асуултыг харуулж, хэрэглэгчийн хариуг авна
3. Хариуг жишиж (том/жижиг үсэг тооцохгүй, нэмэлт зай тооцохгүй) зөв/буруу шийдэнэ
4. Тойрог дуусахад дүнг харуулна
5. Бүх карт давагдсан үед амжилтуудыг харуулж дуусна


session/CardStats.java — Нэг картын статистик
----------------------------------------------
Карт бүрт хэдэн удаа оролдсон, хэдэн зөв, хэдэн буруу гэдгийг тоолно.
isMastered() — шаардлагатай зөв хариуны тоод хүрсэн эсэхийг шалгана.


session/RoundSummary.java — Нэг тойргийн дүн
---------------------------------------------
Тойрог дуусахад ямар карт асуусан, аль нь буруу байсан, хэр удсан
гэдгийг хадгална.
Дараагийн тойрогт RecentMistakesFirstSorter энэ мэдээллийг ашиглана.


session/StudyProgress.java — Явцын мэдээлэл
--------------------------------------------
CardStats (нийт статистик) + RoundSummary (өмнөх тойрог) хоёрыг
нэгтгэж organizer-уудад дамжуулдаг.


achievement/Achievement.java — Амжилтын жагсаалт
--------------------------------------------------
4 амжилт хадгалдаг enum:

ХУРД        : Нэг тойрогт дундаж хариулт 5 сек-аас бага
ЗӨВХӨН ЗӨВ  : Сүүлийн тойрогт бүгдийг зөв хариулсан
ДАВТАГЧ     : Нэг картыг 5+ удаа хариулсан
ИТГЭЛТЭЙ    : Нэг картыг 3+ удаа зөв хариулсан


achievement/AchievementEvaluator.java — Амжилт шалгагч
--------------------------------------------------------
Сесс дуусахад тойргуудын түүх (rounds) ба статистикийг (cardStats)
нягтлаж, хэдэн амжилт нээгдсэнийг тодорхойлж буцаана.


ЕРӨНХИЙ УРСГАЛ
---------------
CardDeckLoader → файлаас унших
StudySession   → асуух / хариу шалгах
CardOrganizer  → картын дараалал тогтоох
AchievementEvaluator → амжилт олгох
